 # Fikelela

Fikelela is an accessibility-first discovery platform for free skills-training opportunities.

The project was created for the Geekulcha Annual Hackathon 2026 under the **Localised Self-Learning Experiences** challenge by **Team Grootman Hacks**.

## Problem

Free online learning opportunities are widely available, but course availability does not always mean course accessibility.

Learners who use assistive technologies may only discover accessibility barriers after enrolling in a course.

## Solution

Fikelela helps learners discover free courses that have been checked for accessibility.

Each reviewed course can include an Access Profile with information such as:

- Screen-reader compatibility
- Keyboard navigation
- Captions
- Transcripts
- Visual dependency
- Downloadable or low-data options
- Verification status

## Hackathon MVP

The initial proof-of-concept will focus on:

- A small set of manually reviewed free technology courses
- Search and filtering
- Accessibility-focused course profiles
- Responsive design
- Screen-reader-friendly navigation
- Human verification of accessibility information
